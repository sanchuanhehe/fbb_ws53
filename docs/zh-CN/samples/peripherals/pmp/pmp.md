# PMP 内存保护

## 学习目标

- 了解 PMP 对物理内存区域访问权限的约束作用。
- 理解地址范围、读写执行权限和异常验证的关系。

## 基本概念

PMP（Physical Memory Protection）用于限制特定地址范围的读、写和执行权限。错误的区域边界或权限可能立即触发访问异常，甚至阻止程序继续运行，因此案例需要设计可恢复的故障验证方式。

## 涉及 API

WS53 当前头文件提供 `uapi_pmp_config()`。
