# 快速入门

欢迎使用 WS53 系列芯片快速入门指南。本指南旨在帮助开发者快速上手 WS53 系列芯片的开发，包含快速开始、环境搭建、开发板等内容。

WS53 系列是集成 Wi-Fi 6、BLE (Bluetooth Low Energy) 5.4 和 SLE (SparkLink Low Energy) 1.0 的 Combo 芯片，支持丰富的网络协议和安全特性。
